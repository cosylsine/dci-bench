# ACORD English source acquisition (2026-10-31)

This source is the official [The-Atticus-Project/acord](https://github.com/The-Atticus-Project/acord) repository at commit `942b33a7c6fed7ead362c7c296401086f8bc0321`. Its repository ZIP contains the nested `ACORD Dataset & ReadMe.zip`; the nested archive is pinned to 3,131,196 bytes, SHA256 `c9e851456a14aed161033b856e9f40f3cc9f46cf7282c2007b143420e93a65c3`, and Git blob SHA1 `6de8c6c01a5221fe7669bc3117cfc02e5bc02fbc`.

The command refuses an existing different file or release. It writes the immutable raw snapshot to `/mnt/afs2/202609/embedding_models/dci-bench/raw_data/gapfill_acord_en/20261031_v1`, the generic-jsonl release to `/mnt/afs2/202609/embedding_models/dci-bench/eval_data/pipeline_v1/gapfill_acord_en/20261031_v1`, and the acquisition receipt to `/mnt/afs2/202609/embedding_models/dci-bench/eval_data/source_research_20261031_v1/acord/acord_20261031_receipt.json`; the grade mapping receipt is beside it as `acord_20261031_label_mapping.json`.

The corresponding source item and quality policy are recorded in `configs/data_pipeline/acord_20261031.json`; the script is the authoritative nested-archive materializer.

The acquisition release contains 3,931 clause documents and all 114 original queries: train 51, valid 6, and test 57. The official test split alone has 57 queries; the DCI adaptation described below combines valid and test while excluding all training queries. The supplemental short/medium/long query file is retained under `raw/source_inputs/acord_dataset/supplemental materials/` and represented row-by-row in `canonical_input/exclusions.jsonl`, but none of those variants is a canonical query.

Every source qrels row is retained in `judgments.jsonl` with `raw_grade`, star value, source split/file/row, and `canonical_relevance`. The canonical mapping is explicit: `canonical_relevance=max(raw_grade-1,0)`, so grade 0/1 (1/2 stars; grade 1 is officially “irrelevant but helpful”) remain judgments but are absent from positive qrels; grade 2/3/4 map to relevance 1/2/3. Unjudged document/query pairs are absent and are never synthesized as negatives. The final release has 126,659 judgments and 1,196 positive qrels (train 520, valid 56, test 620).

The dataset README declares CC BY 4.0 for the data, while the repository wrapper has an MIT `LICENSE`; both are preserved and recorded in the receipt. `verify_release()` reports `state=labels_ready`, 3,931 documents, 114 queries, and 1,196 positive pairs for the acquisition release. This is a data preparation boundary and does not imply retrieval-model or benchmark results.

The benchmark candidate is the immutable derived release `eval_data/pipeline_v1/gapfill_acord_en/20261031_v3`: **3,931 documents, 63 queries, 676 positive pairs**, drawn exclusively from official valid (6) and test (57). All 51 train query IDs are recorded as exclusions. The full corpus remains available; judgments and evidence are restricted to retained queries. The source task is `gapfill_acord_en_v3`. DCI selects dev 10 and test 50 with seed 42 from these 63 queries; these splits do not represent the official ACORD test protocol or score.

Original/parent query identity is the leakage group. Broad legal categories remain host metadata, since a category is not an equivalent query. Supplemental rewrites remain excluded. The earlier all-query v1 acquisition and v2 grouping adaptation are retained as provenance, and are not the selected benchmark source. `scripts/prepare_gapfill_20261031.py derive-acord-heldout` reproduces the v3 selection.
