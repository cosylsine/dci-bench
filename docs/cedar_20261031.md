## 适配定义

`CEDAR.json` 的关系记录没有稳定 annotation ID，只有 `from_text`、`to_text` 和 `relation`。适配器只保留同一场 debate 内能唯一匹配到 source annotation 的边：

- query 是关系 `to_text` 对应的 claim；
- document 是关系 `from_text` 对应的 evidence 或 claim；
- `support` 和 `against` 都表示显式相关，qrel 分数均为 1，并在 evidence metadata 中保留关系类型和关系路径；
- 未把同一 topic 下的文本、正反方立场或相似主题自动连成 qrels；
- source/target 角色冲突、端点文本重复歧义、未知端点和同一 pair 的 support/against 冲突均排除并记录。
- claim 既可以是 query，也可以作为 relation 的 source document；query metadata 保留 target claim 的 `source_annotation_id`，evidence 保留 source/target annotation IDs，reviewed adapter 可由 alias manifest 解析 `canonical_query_document_id` 和 `self_match_document_ids`，供导出排名时移除 query 自身。

因此这是忠实使用 CEDAR 关系标注的 retrieval adapter，不声称是官方 retrieval benchmark。论文描述的是 claim 附近的候选证据人工标注，不能把未标注候选文档当作负例或声称全库穷尽判断。

## 已构建结果

原始 `CEDAR.json` 解析得到 600 records、13,777 个 claim annotation units、20,193 个 evidence annotation units。基础 release 保留 33,970 个 occurrence-level source annotation documents、9,522 个有显式正边的 queries、13,884 个唯一 positive pairs 和 13,884 条 evidence rows。审计排除 1,330 条角色未知/冲突关系、75 条端点文本歧义和 3 个 support/against 冲突 pair；精确重复 document 文本组为 6,436（多出的 occurrence 为 8,176）。原文路径、annotation ID、topic、debate、offset 和文本均保留在 metadata。

基础转换记录 topic 的 SHA256 前 16 位作为 `group_id`，固定 seed 42，按稳定哈希将有保留 query 的 296 个 topic group 分为 dev 10、test 50、train 236；topic 不跨 split。基础 query 数量为 dev 258、test 1,769、train 7,495。这个分组和确定性文档 ID 列表只用于审计；它们不是 ranked Lite/Full pool，也不构成 readiness 证据。

基础 pipeline release 的状态是 **`review_required`**，receipt 的 `ready_for_benchmark` 为 `false`。其中 6,107 条 review 行全部是 `equivalent_unlabelled_document`，涉及 4,180 个 query；基础 release 保留它们以供审计。

二次 reviewed release `/eval_data/pipeline_v1/gapfill_cedar_zh/20261031_v1_reviewed/` 在不覆盖基础 bytes 的前提下完成了审查转换：排除这 4,180 个完整 query，按 decoded text 折叠 8,176 个 exact-text alias occurrence，并保留每个原始 document ID、annotation ID、JSON pointer 和 relation pointer。折叠后没有 support/against 冲突，审计为 `status=pass`、`review_required=0`、`exclusions=0`，自然 pipeline 状态为 **`labels_ready`**；计数为 25,794 documents、241 queries、463 positive pairs/evidence rows。

为满足主 sampler 的逐 query 配额和 topic 隔离，reviewed release 从 5,342 个未歧义 query 中每个 topic group 确定性保留一条，实际 `sample_global_query_splits(seed=42, dev=10, test=50, smoke=1)` 已通过，dev/test 为 10/50 且无 group leakage。reviewed receipt 仍为 `ready_for_benchmark=false`，因为没有构建 KaLM ranked pools；主流程必须另行生成真实 Lite⊂Full 排名池。CEDAR relation 是局部候选标注，不能把未标注文档当作穷尽负例。
