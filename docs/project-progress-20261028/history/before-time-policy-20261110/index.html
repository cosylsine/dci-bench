评测流程

同一份query、两档嵌套候选池、相同执行预算；按阶段保留可复核记录。

  1. 01 / 资格与隔离确定20个任务

    原生中英的语料、query、qrels匹配；先去重与同源组隔离。缺格保持阻塞，译本单列。

  2. 02 / 采样开发10 · 正式50

    固定输入排序，random无放回，seed 42。Smoke取开发集1题；保存算法版本、输入摘要和选中ID，保留策略接口。

  3. 03 / 候选池Lite ⊂ Full

    保留全部正例，再按固定检索顺序补齐至200 / 1000。正例超过200的query排除并计数。

  4. 04 / 执行相同预算与隔离

    同任务/profile批处理，每题独立Pi会话；有界工作区预取、复制后正文hash检查、逐bash Bubblewrap隔离及退出清理。

  5. 05 / 评分与归档宿主机评分

    模型提交ranked_doc_ids，qrels仅宿主机可见。逐题记录结果、费用与计时，失败和重试留痕；通过身份与hash校验后恢复。
